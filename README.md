# 개인 챗봇

휴대폰 홈 화면에 설치해 혼자 쓰는 챗봇입니다. RPG 캐릭터를 만들듯 인물 설정을 적고, 카카오톡이나 왓츠앱 대화 내보내기 파일을 넣으면 그 사람의 말투와 둘 사이의 기억을 입힐 수 있습니다. 인물은 내 정보와 지난 대화를 기억하고, 오랜만에 앱을 열면 먼저 말을 겁니다.

## 알아둘 점

- **데이터는 이 휴대폰에만 저장됩니다.** 서버가 없습니다. 대화 내용은 AI 답변을 받을 때만 설정에서 고른 AI 제공사(Anthropic 또는 Google)로 전송됩니다.
- **API 키는 이 휴대폰에만 저장됩니다.** 백업 파일에도 들어가지 않습니다.
- **브라우저 데이터를 지우면 모든 내용이 사라집니다.** 설정에서 가끔 백업을 내보내 두세요.
- 앱에는 대화 주제 필터가 없습니다. 다만 사용하는 AI 모델은 고른 제공사(Anthropic 또는 Google)의 이용 정책을 따르며, 모델이 답변을 거절하면 그 응답이 그대로 표시됩니다.
- 대화 내보내기 파일에는 상대방의 사적인 대화가 들어 있습니다. 혼자 쓰는 용도로만 사용하세요.

## 1. API 키 발급받기

둘 중 하나만 있으면 됩니다. 설정 탭의 "AI 제공사"에서 고른 쪽의 키를 넣습니다.

**Anthropic (Claude)**

1. https://console.anthropic.com 에 가입합니다.
2. 결제 수단을 등록하고 크레딧을 충전합니다. 쓴 만큼 요금이 나옵니다.
3. API Keys 메뉴에서 키를 만들고 복사해 둡니다 (`sk-ant-`로 시작).

**Google (Gemini)**

1. https://aistudio.google.com 에 Google 계정으로 들어갑니다.
2. "Get API key"에서 키를 만들고 복사해 둡니다.

제공사를 바꾸면 인물의 말투가 조금 달라질 수 있습니다. 제공사별 키와 모델 이름은 따로 기억되므로 다시 바꿔도 다시 넣을 필요가 없습니다.

## 2. 인터넷에 올리기 (GitHub Pages, 무료)

홈 화면에 설치하려면 https 주소가 필요합니다. 앱 파일만 올라가며, 내 데이터는 올라가지 않습니다.

1. https://github.com 에 가입하고 새 저장소(repository)를 만듭니다. 공개(Public)로 만들어야 무료로 Pages를 쓸 수 있습니다.
2. 이 폴더를 그 저장소에 올립니다.
   ```bash
   git remote add origin https://github.com/내아이디/저장소이름.git
   git push -u origin main
   ```
3. 저장소의 Settings → Pages → Source를 **GitHub Actions**로 바꿉니다.
4. 몇 분 뒤 Actions 탭에서 배포가 끝나면 `https://내아이디.github.io/저장소이름/` 주소로 열립니다.

## 3. 휴대폰 홈 화면에 추가하기

- **아이폰:** Safari로 주소를 열고 → 공유 버튼 → "홈 화면에 추가"
- **안드로이드:** Chrome으로 주소를 열고 → 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"

홈 화면의 아이콘으로 열면 주소창 없이 앱처럼 열립니다.

## 4. 처음 쓰는 순서

1. **설정** 탭: AI 제공사를 고르고 API 키를 붙여 넣은 뒤 저장합니다.
2. **내 정보** 탭: 기본 정보, 이력서, 취미, 과거 이야기를 적습니다. txt 파일을 첨부해도 됩니다.
3. **인물** 탭: 이름, 관계, 성격, 말투, 배경 설정을 적습니다.
   - "대화 파일 가져오기"를 누르고 카카오톡 또는 왓츠앱 내보내기 txt 파일을 넣으면 초안을 자동으로 만들어 줍니다.
   - 파일이 클수록 시간과 AI 사용료가 늘어납니다. 처음에는 "최근 3개월"로 해보세요.
4. **대화** 탭: 대화를 시작합니다. 한 시간 이상 지나 다시 열면 인물이 먼저 말을 겁니다.

### 대화 내보내기 파일 만드는 법

- **카카오톡:** 대화방 → 메뉴(≡) → 설정(톱니바퀴) → 대화 내용 내보내기 → 텍스트만 보내기
- **왓츠앱:** 대화방 → 메뉴 → 더보기 → 대화 내보내기 → 미디어 없이

## 5. 백업과 인물 바꾸기

- **백업:** 설정 → 백업 내보내기. 휴대폰을 바꿀 때는 새 휴대폰에서 백업 가져오기를 하고 AI 제공사와 API 키를 다시 넣습니다.
- **인물 바꾸기:** 인물 탭 맨 아래 "새 인물로 바꾸기". 이전 인물의 설정과 기억은 보관됩니다.

## 개발

```bash
npm install
npm test        # 전체 시험
npm run dev     # 개발 서버
npm run build   # dist 폴더에 배포용 파일 생성
```

설계 문서는 `docs/superpowers/specs/`, 구현 계획은 `docs/superpowers/plans/`에 있습니다.
